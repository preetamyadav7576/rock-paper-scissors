## 🎯 About The Project

**Rock Paper Scissors** is a fun and interactive browser-based game where you compete against the computer.

Choose your move:

> ✊ **Rock**
> 📄 **Paper**
> ✂️ **Scissors**

The computer randomly selects its move, and JavaScript determines the winner instantly. ⚡

## 🧠 How The Game Works

The basic game rules are:

```text
✊ Rock     beats     ✂️ Scissors
📄 Paper    beats     ✊ Rock
✂️ Scissors beats     📄 Paper
```

If both players choose the same option:

```text
🤝 It's a Draw!
```

Otherwise, the winning choice gets the point. 🏆
